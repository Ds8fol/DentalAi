# DentalAI

Учебный/исследовательский прототип ИИ-помощника для стоматологии.

## Структура
- index.html — интерфейс
- style.css — дизайн
- script.js — интерактивность

## Первый этап
Сайт умеет:
- принимать изображение;
- показывать предпросмотр;
- имитировать экран результата;
- показывать интерфейс чата.

## Важно
На этом этапе проект не выполняет медицинскую диагностику. Настоящую ML-модель подключаем только после отдельной проверки модели и данных.

## Следующие этапы
1. GitHub Pages.
2. Научная база.
3. Модель компьютерного зрения.
4. API/серверная часть.
5. Тестирование и метрики.
6. Конкурсная презентация.
